# 🎵 محول الفيديو إلى MP3 | Video to MP3 Converter

## المميزات الرئيسية | Main Features

### 🌟 باللغة العربية
- ✅ **تحويل سريع**: حول أي فيديو إلى MP3 في ثوانٍ
- ✅ **أمان تام**: جميع العمليات تتم في متصفحك - لا يتم رفع أي ملفات
- ✅ **جودة عالية**: صوت بجودة 192 كيلوبت
- ✅ **سهل الاستخدام**: واجهة بسيطة وسهلة
- ✅ **مجاني بالكامل**: بدون قيود أو رسوم
- ✅ **جميع الصيغ**: يدعم MP4, AVI, MOV, MKV, WebM, FLV, WMV

### 🌟 In English
- ✅ **Fast Conversion**: Convert any video to MP3 in seconds
- ✅ **100% Secure**: All processing happens in your browser - no uploads
- ✅ **High Quality**: Audio at 192 kbps quality
- ✅ **Easy to Use**: Simple and intuitive interface
- ✅ **Completely Free**: No limits or fees
- ✅ **All Formats**: Supports MP4, AVI, MOV, MKV, WebM, FLV, WMV

## كيفية الاستخدام | How to Use

### بالعربية:
1. انقر على "اختيار الفيديو" أو اسحب الملف إلى المربع
2. انتظر تحميل الفيديو وشاهد المعاينة
3. اضغط على زر "تحويل إلى MP3"
4. انتظر حتى يكتمل التحويل
5. استمع للصوت أو حمّل ملف MP3

### In English:
1. Click "Choose Video" or drag & drop your file
2. Wait for video to load and preview
3. Click the "Convert to MP3" button
4. Wait for conversion to complete
5. Listen to audio or download the MP3 file

## التقنيات المستخدمة | Technologies Used

- ⚛️ **React 18** with TypeScript
- 🎨 **Tailwind CSS** for styling
- 🎬 **FFmpeg.wasm** for video to audio conversion
- ⚡ **Vite** for fast builds
- 🔧 **Modern JavaScript** (ES2020+)

## التثبيت والتشغيل | Installation & Running

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## الملاحظات الفنية | Technical Notes

- يتم تحميل FFmpeg عند أول استخدام للتطبيق
- جميع عمليات التحويل تتم محلياً في المتصفح
- لا يتم إرسال أو تخزين أي بيانات على خوادم خارجية
- يعمل على جميع المتصفحات الحديثة

## المتطلبات | Requirements

- متصفح حديث يدعم WebAssembly
- اتصال إنترنت لتحميل FFmpeg في المرة الأولى فقط
- ذاكرة كافية لمعالجة الفيديو (يعتمد على حجم الملف)
